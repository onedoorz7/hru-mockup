# ״איך את.ה?״ - מוקאפ עיצוב ומסירה לפיתוח

מוקאפ סטטי לאתר ״איך את.ה?״ - פרויקט מידע פסיכו-חינוכי מבית קולקטיב עיקר, בהפקת פרובו. הריפו הזה הוא נקודת המוצא להמשך הפיתוח: הוא כולל את העיצוב העדכני, את הגרסאות הקודמות, ואת ההנחיות המלאות.

**זה אינו האתר הפעיל.** כל הטקסטים, המספרים, שמות הארגונים והלוגואים הם תוכן הדגמה, עד לאישור התכנים הסופיים. אין להסתמך על המידע בעמודים אלה. במצב חירום חייגו 101; לתמיכה נפשית מיידית - ער״ן, 1201.

## הרצה מקומית

אין תהליך build - אתר סטטי נקי:

```bash
git clone https://github.com/onedoorz7/hru-mockup
cd hru-mockup
python3 -m http.server 8000   # או: npx serve
# http://localhost:8000
```

## מבנה

| נתיב | מה זה |
|---|---|
| `index.html` | עמוד הבית: חיפוש חופשי, נושאים, פס אובדנות שקט, ארגז כלים, פס שותפים |
| `topics.html` | שכבת הפסיכו-חינוך: כרטיסי בנטו עם 4-6 נקודות מרגיעות לנושא |
| `search.html` | תוצאות חיפוש: סינון לקרוא/לצפות/לעשות, מעט תוצאות + ״עוד״ (כולל מצב ללא תוצאות ומצב שאילתה רגישה) |
| `article.html` | עמוד תוכן, עם CTA עזרה בסופו |
| `partner.html`, `partners.html` | עמוד ארגון בודד ורשימת כלל הארגונים |
| `help.html` | קבלת עזרה, כולל אזור `#crisis` עם שני מסלולי תמיכה |
| `about.html` | על הפרויקט |
| `css/b.css` | כל מערכת העיצוב (טוקנים, רכיבים, מובייל, תנועה) |
| `js/b.js` | תפריט, אנימציות reveal, ה-placeholder המתחלף בחיפוש |
| `v1/` | צילום קפוא של גרסה 1 - לא נוגעים |
| `docs/` | ההנחיות שבטבלה למעלה |

## ניהול גרסאות

- העיצוב העדכני יושב תמיד בשורש. גרסאות קודמות קפואות בתיקיות `v1/`, `v2/`... וגם כענפי גיט (`v1`, `v2`).
- לפני סבב עיצוב חדש: מעתיקים את קובצי השורש לתיקיית `vN/` חדשה, ורק אז משנים.
- כל push ל-`main` נפרס אוטומטית ל-GitHub Pages. לוודא שריצת ״pages build and deployment״ בלשונית Actions ירוקה - דחיפה לבדה אינה ״עלה לאוויר״.
